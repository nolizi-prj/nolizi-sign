### 1. Coherence & Internal Consistency

- **Semantics of Absence vs. Nullification (§S1, §S2):**
  - Identifies the root cause in `service/src/durable.ts`: `title` correctly applied `?? sub.title` when omitted, whereas `message` evaluated `body.message != null ? ... : null`, causing any PATCH omitting `message` (such as the expiration & reminders settings dialog in `frontend/src/views/EnvelopeDetailView.vue`) to overwrite the stored message with `NULL`.
  - §S2 addresses this by distinguishing `body.message === undefined` (field omitted; retain stored `sub.message ?? null`) from `body.message === null` (field explicitly cleared; write `NULL`).
  - Correctly flags that using `body.message ?? sub.message` would introduce a reverse defect (treating explicit `null` as absent and rendering the covering message unremovable).

- **Audit Trail & Terminal Status Guard Interlocking (§S3):**
  - Extends the `corrected` audit event's `changed` list to include `'title'` and `'message'` when their post-patch values differ from the pre-patch snapshot `sub.title` and `sub.message`.
  - Prevents audit spam by comparing against stored snapshot values rather than body key presence (since the details dialog re-sends both fields on every save).
