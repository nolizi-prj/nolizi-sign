## 3. Acceptance Case Invariants & Falsifiability ([`L-006`](file:///home/m/dev/governance/lessons/L-006-tests-that-cannot-fail.md))

The acceptance suite in [`frontend/src/ci-covers-service.spec.ts`](file:///home/m/dev/pumasi-sign/frontend/src/ci-covers-service.spec.ts) contains deterministic assertions directly coupled to their specification clauses:

- **A-100 (Reader Guard):** Validates the YAML parser against the real `ci.yaml` structure, preventing vacuous passes caused by regex mismatches.
- **A-101 (`S1a`):** Asserts the existence of a `service` job in `ci.yaml` with a step running `npm test` in `service/`.
- **A-102 (`S1b`):** Asserts `npm run build` runs in `service/` strictly before the `npm test` step.
- **A-103 (Premise Guard):** Verifies that `service/package.json`'s test script targets `dist/` and confirms that executing it in an empty directory exits `0` with `# tests 0`.
- **A-104 (`S1c`):** Directly executes `.github/scripts/assert-service-suite-ran.sh` against test fixtures, asserting exit `0` on valid runs and exit `1` on unbuilt trees, partial compilation, zero-pass runs, failed runs, malformed summaries, and missing sources.
- **A-105 (`S1c`):** Asserts the `service` job invokes `assert-service-suite-ran.sh` after the suite step and verifies the script file exists with executable permissions.
- **A-106 (`S2a`):** Asserts no `vue-tsc` command in `ci.yaml` is invoked without the `-b` flag.
- **A-107 (`S3a`, `S3b`, `S3d`):** Asserts `CLAUDE.md` names `sign.pumasi.ai`, `service/`, `Cloudflare Worker`, `wrangler`, and `Q-018`, and verifies that the Cloudflare Worker documentation precedes Railway.
- **A-108 (`S3c`):** Asserts `CLAUDE.md` does not document `vue-tsc --noEmit`.
- **A-109 (`S4a–c`):** Asserts the preservation of `backend`, `frontend`, `e2e` jobs, both `service/` test files, and all `backend/` Python test cases.
