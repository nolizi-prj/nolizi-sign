## 3. Acceptance Test Invariants & Falsifiability ([L-006](file:///home/m/dev/pumasi/lessons/L-006-tests-that-cannot-fail.md))

All six frozen acceptance cases in [`frontend/src/landing-claims.spec.ts`](file:///home/m/dev/pumasi-sign/frontend/src/landing-claims.spec.ts) and [`frontend/e2e/landing-page.spec.ts`](file:///home/m/dev/pumasi-sign/frontend/e2e/landing-page.spec.ts) specify deterministic assertions that cannot pass vacuously:

1. **A-001 (Stage register match):** Asserts `STAGE === STAGE_MD.match(/\*\*Current stage:\*\*\s*`([a-z]+)`/)[1]`. Fails immediately if the constant and register disagree.
2. **A-002 (Single stage word occurrence & derivation):**
   - Asserts `LANDING_VUE.match(/\b(alpha|beta|launched)\b/gi)` is empty (fails on the existing shipped file).
   - Asserts `stage.ts` contains exactly one stage word inside `STAGE = "<word>"`.
   - Asserts `STAGE_LABEL` lowercases to `STAGE` and `STAGE_BADGE` starts with `STAGE.toUpperCase()` and contains `"ACTIVE DEVELOPMENT"`.
3. **A-003 (Verification of all `$` figures):** Extracts all `$`-denominated figures from `LandingView.vue` and asserts every one appears in `roadmap/MARKET.md`. Fails on the unbacked figures `$25` and `$65`.
4. **A-004 (Plan names, metering units, and citation):**
   - Asserts every competitor table cell containing `$` includes a plan name parsed from `MARKET.md`.
   - Asserts DocuSign priced cells match `/\buser\b/i` and SignWell priced cells match `/\bsender/i` while rejecting `/\/\s*user\b/i` (fails on the shipped `"$10 – $30 / user / mo"`).
   - Asserts `LandingView.vue` includes the fetched date from `MARKET.md` and quotes `"MARKET.md"`.
5. **A-005 (Apache-2.0 Scope Guard):** Asserts exact byte preservation of the three shipped Apache-2.0 strings at `10a523d` until Q-021 is resolved.
6. **A-006 (Rendered Browser Surface):** Playwright e2e test asserting the painted badge starts with `alpha`, the body contains no conflicting stage words, and rendered table prices exist in `MARKET.md`.

None of the acceptance cases rely on conditional paths, race conditions, or decorative assertions.

## 4. Edge Cases & Boundary Conditions

- **S2d (Envelope Limit Row):** §S2d specifies that DocuSign's envelope limit row must state the limit as published (per user per year on named plans). In the test suite, A-004 targets cells containing `$` figures. Because envelope limit cells (e.g., `"100/user/year"`) do not carry `$`, they are guided by §S2d and the general citation requirement (A-004 test 3).
- **Quote Style in `stage.ts`:** A-002 tests `STAGE\s*=\s*"${found[0]}"`, requiring double quotes in `stage.ts`, aligning with TypeScript formatting conventions.
- **Test ID Contract:** A-006 targets `page.getByTestId("stage-badge")`, specifying the test locator required on the rendered component.
